# Spidey Pack for Super Mario 64

Spidey Pack è un character pack per il decomp di **Super Mario 64** che sostituisce Mario con **Spider-Man**.

## Contenuto

* Modello completo di Spider-Man
* Texture personalizzate
* Supporto alle animazioni originali di Mario
* Varianti per occhi, mani, cappello e Metal Mario
* `model.inc.c`
* `geo.inc.c`
* Suoni di Tobey Maguire
* Texture del Power Meter

Il pack è stato adattato per essere compatibile con la struttura del **SM64 decomp**.

## Note

Questo progetto modifica solamente l'aspetto del personaggio e utilizza il sistema di animazioni e comportamento originale di Mario.
